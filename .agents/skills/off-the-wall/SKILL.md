# Off the Wall

Create branded sticky-note style callouts that feel pinned into the page rather than dropped in as generic badges.

## Use when
- The user asks for handwritten, sticky-note, order-note, pinned-note, or off-the-wall text treatments
- A page needs short informal callouts in nearby empty space
- The brand needs a casual personal note without losing polish

## Rules
- Treat it as a decorative information callout, not a main CTA container
- Keep notes compact and placed in negative space near the relevant content
- Use a sticky-note paper look with slight rotation and subtle taped/pinned detail
- Default brand expression: CCGC neon-green note surface, black readable relaxed sans/comic-like text
- Keep text short, high-contrast, and easy to read on mobile
- Never let notes cover product imagery, prices, or form controls
- Prefer a casual handwritten/comic-adjacent sans stack such as Comic Neue / Trebuchet / system sans
- Use only one or two notes per section so the page stays premium

## Recommended implementation shape
- Reusable StickyNote component
- Max width about 16rem to 18rem
- Slight rotation between -3deg and 3deg
- Soft shadow, subtle border, taped top detail
- Black text, medium weight, relaxed line-height

## Current brand phrasing
Default approved note text for account/signup encouragement:
"Sign in once. Order easier every time after."
